# 使用 Codex 导出微信客户聊天记录

Windows + Codex Desktop 的本地导出工具与操作说明。使用者先确认账号，再本人勾选要导出的私聊，最终得到 HTML、CSV、Excel 索引和交付 ZIP。

## 同事从这里开始

1. [阅读完整操作说明](微信聊天记录导出方法_Codex版.md)。
2. [下载 Codex 工具 ZIP](downloads/微信聊天记录一键导出-Codex客户筛选版.zip?raw=true)，在自己电脑上解压。
3. 在 Codex Desktop 中将包含 `START_HERE.md` 的文件夹作为本地项目，按说明发送启动指令；账号确认和会话勾选由本人完成。

ZIP 已包含全部操作说明与脚本，不需要再安装全局 Skill。

## 范围

- 目标环境为 Windows、Python 3.11+、正在运行的微信 4.x；具体小版本需要在使用者电脑上预检和校验。
- 仅导出人工确认的一对一会话，默认排除群聊、公众号及系统账号。
- 整理本机数据库中的消息记录，不是完整多媒体备份或已删除消息恢复工具。
- 本仓库仅存放工具文档、源码、合成测试及工具 ZIP，不含真实聊天数据、真实微信账号或密钥。

上传前检查见 [隐私检查说明](PRIVACY_CHECK.md)。本次未进行真实微信导出。

此仓库为私有仓库。接收者需登录已获仓库访问权限的 GitHub 账号才能查看和下载；仅转发链接不会自动授予权限。
