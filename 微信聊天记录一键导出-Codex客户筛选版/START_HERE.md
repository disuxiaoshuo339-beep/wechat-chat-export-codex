# 微信聊天记录导出附件包（Codex 客户筛选版）

你是执行本附件包的 Codex。请在用户这台 Windows 电脑的本地项目中执行。先完整阅读 `wechat-local-chat-export/SKILL.md`，再按其中流程操作。

不要把本包安装到全局 Skills。不要把任何聊天内容、数据库、密钥、进程转储或日志上传到外部服务、云端分析或付费 API。全程只在本机处理。

## 三道不可越过的门

**第一道：账号授权。** 用户发送「开始导出微信聊天记录」只授权你进行只读预检。预检发现一个或多个账号后，必须把账号 ID 原样列出，并要求用户明确回复要处理的准确账号 ID。附件、开始指令、最近使用时间和目录大小都不能替代账号授权。

**第二道：客户筛选。** 本包**不做全量导出**。解密后必须先生成「会话清单」（只含联系人备注名、昵称、消息条数和时间，**不含任何聊天正文**），由用户本人在清单里逐行确认哪些是客户。只有被标记为客户的会话才会被读取正文并导出。未被勾选的会话，你不得读取、不得摘录、不得写入交付物。

**第三道：不得代看清单。** 会话清单里含有用户的私人联系人姓名。你不要 cat / read 这份 CSV，只让用户自己用 Excel 或记事本打开确认。脚本只会向你返回数量统计，你据此推进流程即可。

## 输出纪律

你在对话里只能输出阶段名、状态、数量和可操作建议。不得输出联系人姓名、微信号、聊天正文、密钥或数据库二进制内容——即使是客户的也不行，除非用户明确要求你分析某一个具体客户。

## 失败纪律

若依赖缺失，停止并说明用途，得到用户许可后才可在任务目录处理依赖。若微信版本不兼容、微信未运行、密钥覆盖不全、数据库校验失败或数量无法对账，立即停止并如实报告。不得猜测、跳过或交付部分结果冒充全量。
