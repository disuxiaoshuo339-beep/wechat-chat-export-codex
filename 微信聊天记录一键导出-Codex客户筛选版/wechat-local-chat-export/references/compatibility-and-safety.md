# 兼容性与安全边界

- 目标环境：Windows、可执行本地命令的 Codex Desktop 任务、正在运行的微信 4.x。
- Python 3.11+；需要 `pycryptodomex` 与 zstd 支持（Python 3.14 自带 `compression.zstd`，否则用 `zstandard`）；`openpyxl` 可选，缺失时索引降级为 CSV。
- 采用运行中微信进程和本地数据库的只读快照；源目录不修改、不删除、不覆盖。
- 账号授权必须精确到预检列出的账号 ID。发现多个账号时尤其不能代选。
- 密钥仅在内存中短暂存在，使用后清零；不得写入文件、聊天回复、日志或 ZIP。
- 输出和临时工作目录必须位于微信数据目录之外。
- 仅支持经校验的 SQLCipher 页面参数和当前 WAL 盐；过期或未提交 WAL 帧不得合并。
- 默认排除群聊、公众号和系统账号；`@openim` 私聊保留。
- **筛选闸门**：一对一私聊也不全量导出。先生成只含元数据的会话清单（生成过程不 SELECT 任何消息正文字段），由用户勾选后，只对勾中的会话读取正文。未勾选会话在发出正文查询之前即被跳过。
- **清单不代看**：`会话清单.csv` 含用户私人联系人姓名，AI 不读取该文件，只接收脚本返回的数量统计。
- **明文清理**：解密后的 `source_copy` 与 `private` 目录含全部会话（包括未勾选的私人会话），交付完成后由 `finalize_delivery.py --purge-workspace` 删除。
- 所有文件都在本机处理。禁止调用外部上传、云端分析或付费 API。
- 安装任何第三方依赖前必须获得用户许可。
