# AGENTS.md

本目录是「微信聊天记录一键导出（Codex 客户筛选版）」附件包。

执行前必须先读 `START_HERE.md`，再读 `wechat-local-chat-export/SKILL.md`，然后严格按 SKILL 里的流程操作。

三条硬约束，摘录在此，细则见上述两个文件：

1. 账号必须由用户明确授权到准确的 account_id，不得代选。
2. 必须经过「会话清单 → 用户人工勾选 → 只导出勾中会话」这道闸门；不做全量导出。你不要读取 `会话清单.csv` 本身，它含用户私人联系人姓名。
3. 全程本机处理。不上传聊天内容、数据库、密钥或日志到任何外部服务。对话输出里只给阶段、状态和数字，不给姓名和正文。
